# @pdf-layouter/react

`<LayoutDesigner />` for React and Next.js, plus `useLayoutDocument` and the Next config adapter `withPdfLayouter` (`@pdf-layouter/react/next`).

```tsx
import { LayoutDesigner } from '@pdf-layouter/react'

<LayoutDesigner value={layout} onChange={setLayout} placeholders={catalog} sampleData={sample} />
```

Full documentation: <https://github.com/pseuss/pdf-layouter#readme>
